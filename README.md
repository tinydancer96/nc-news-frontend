An extension to the NC-News-Backend project (https://github.com/tinydancer96/backend-project-nc-news). This project utilises the react to handle building user interfaces through components and react router to handle server side rendering and client side routing. 

The app is a new sharing website where users can search for articles, articles by topic, users and like, comment and post on articles. Users are also able to post their own articles within the website.
